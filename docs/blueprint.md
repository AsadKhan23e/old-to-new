# **App Name**: CashbookPro

## Core Features:

- App Layout: Mobile-first layout with a title bar displaying 'CashbookPro' and a bottom navigation bar.
- Bottom Navigation: Navigation with three tabs: Dashboard, Customers, and Settings.
- Placeholder Pages: Create placeholder pages for all routes including login, signup, dashboard, customers, individual customer view, new customer creation, items, transactions, reminders, reports, and settings.
- Theming: Export a theme file with high-contrast colors and large readable fonts.
- RTL support: Provide support for right-to-left (RTL) layouts with Urdu text. Apply translations with the help of an AI powered localization tool

## Style Guidelines:

- Primary color: Strong blue (#2962FF) to convey trust and stability in financial matters.
- Background color: Soft gray (#F0F2F5) for a clean, professional backdrop.
- Accent color: Vivid orange (#FF6B00) for key actions and alerts.
- Body and headline font: 'PT Sans' (sans-serif) for readability in both English and Urdu.
- Recommendation: Implement larger font sizes to ensure accessibility, especially for users reading Urdu script. Note: currently only Google Fonts are supported.
- Mobile-first responsive design for usability on smaller screens. Center content and utilize spacing to avoid clutter.
- Simple, geometric icons that are easily understandable and recognizable, reinforcing intuitive navigation.
